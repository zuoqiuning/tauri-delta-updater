# v0.3.0 — Inno Setup 全量安装、一条命令发布与发布源体检

发布日期：2026-11-08
对比基线：`v0.2.1`（2026-11-07）

## 升级注意

- **Inno Setup 宿主**：必须显式声明 `installer_kind(Inno)`，并让全量更新走本引擎的
  `install_full`。官方 `tauri-plugin-updater` 只会传 NSIS 参数，不认识 Inno。
  同时确认 `.iss` 的 `[Run]` 负责重启应用，且**不要**加 `skipifsilent`。
- **用结构体字面量构造配置/清单的代码**：`UpdateConfig` / `UpdateManifest` /
  `PlatformInfo` 现在是 `#[non_exhaustive]`，请改用 builder 或 serde；通过
  builder/serde 配置的调用方不受影响。
- **安全默认收紧**：默认拒绝旧格式 minisign 签名与非回环 `http://`。仍需要兼容的
  宿主请显式开启 `allow_legacy_signatures(true)` / `allow_insecure_transport(true)`；
  本地回环 `http://127.0.0.1` 仍默认允许。

## 新增

- **Inno Setup 静默更新**：`Passive` 显示进度但不进入向导，`Quiet` 完全无界面；
  两者都不会自动重启系统。配置方式：
  `.installer_kind(InstallerKind::Inno)`，插件配置写 `"installer_kind": "inno"`。
- **一条命令发布**：`cargo delta release` 生成清单、补丁、签名与报告；
  发布逻辑同时以 `release` 模块提供，便于接自定义流水线。
- **发布源体检**：`cargo delta doctor` 检查线上清单签名、安装包体积、补丁哈希与
  补丁链；`--deep` 额外验安装包签名，`--json` 供 CI 归档。
- **回滚提示**：更新失败并恢复旧版本后，Windows 弹窗、macOS/Linux 发通知，
  不再静默回退；可用 `rollback_notice: false` 关闭。
- **发布端辅助**：`generate --sha256sums` 一次产出全量校验和；
  `--legacy-patch` 为旧客户端输出未压缩补丁。

## 修复

- 跨代际升级时能正确识别旧引擎脚本并确认启动，不再出现“新版本已启动却被旧脚本回滚”。
- 已准备好的待安装更新在“检查到最新版本”或“下载更高版本失败”时不再被误删。
- `cargo delta init` 默认写 `"0.3"` 依赖；`--check` 对 git 依赖只告警，不阻断 CI。
- Linux `min_os` 文档改为内核版本语义，避免把发行版版本当成内核版本而错误阻断。

## 验证边界

- macOS Gatekeeper/公证、Windows UAC/单实例、Linux 提权未在本仓库真机验证；
  CI 只做静态与合成脚本断言。
- 引擎 `install_full` + Inno 的静默安装已做参数单测，真实安装器行为需按
  `docs/DEVICE_TESTS.md` 在桌面会话执行 `Passive` / `Quiet` 各一次。
- `cargo delta doctor` 只在本地 mock server 端到端验证过，未对真实 CDN 执行。

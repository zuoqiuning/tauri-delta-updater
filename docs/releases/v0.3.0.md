# v0.3.0 — Inno Setup 全量安装、一条命令发布与发布源体检

发布日期：2026-11-08
对比基线：`v0.2.1`（2026-11-07，crates.io 已发布，不可覆盖）

0.3.0 是 **MINOR**，包含破坏性变更（`VERSIONING.md` §1.2）：

1. `InstallerKind` 新增 `Inno` 并标记 `#[non_exhaustive]`；
2. `UpdateConfig` 新增 `installer_kind` 并标记 `#[non_exhaustive]`；
3. `UpdateManifest` / `PlatformInfo` 标记 `#[non_exhaustive]`；
4. `allow_legacy_signatures` / `allow_insecure_transport` 默认改为 `false`。

用结构体字面量构造上述结构体的代码需要改用 builder 或 serde；通过 builder /
serde 读取的调用方只需检查两个安全开关是否显式开启。

## 新增

- **Inno Setup 全量安装**：`installer_kind(InstallerKind::Inno)` 或插件配置
  `"installer_kind": "inno"`；`/SILENT /VERYSILENT /NORESTART /SP-` 三态映射。
  只影响引擎 `install_full`；官方 `tauri-plugin-updater` 不支持 Inno。
- **一条命令发布**：`cargo delta release`（与 `generate` 参数等价，`--from`
  可重复），发布逻辑同时以 `release` 模块公开给自定义流水线。
- **发布源体检**：`cargo delta doctor`，校验清单签名、版本绑定、安装包体积、
  补丁哈希、补丁链与整包清单；`--deep` 验安装包签名，`--json` 供 CI 归档。
- **回滚提示**：静默回滚后 Windows 弹消息框、macOS/Linux 发桌面通知；
  `rollback_notice` 可关闭。
- **发布端防错**：`generate --sha256sums`、`--legacy-patch`；发布脚本与
  `generate` 共用同一实现。

## 验证边界

CI 覆盖静态断言、合成脚本与本地 mock server；以下路径**未在本仓库真机验证**：

- macOS `.app` 目录切换的 Gatekeeper / 公证行为；
- Windows UAC 提权、`install_and_exit` 与 `tauri-plugin-single-instance` 的锁释放；
- Linux 提权（`sudo -n` / `pkexec`）与降权启动；
- 引擎 `install_full` + Inno Setup 的静默安装：参数映射有单测，真实安装器
  行为需按 `docs/DEVICE_TESTS.md` 在桌面会话执行 `Passive` / `Quiet` 各一次；
- `cargo delta doctor` 只对本地 mock server 做过端到端验证，未对真实 COS 桶执行。

Inno 宿主升级前必须确认：全量路径走引擎 `install_full`（不是官方 updater），
且 `.iss` 的 `[Run]` 负责重启应用、不能加 `skipifsilent`。

遇到问题请附 `tdx_update.log` 与 `tdx_events.jsonl` 开 issue。

# v0.4.0 — 结构化失败原因、默认权限收窄与更安全的发布

发布日期：2026-11-09
对比基线：`v0.3.0`（2026-11-08）

**安装**：[crates.io](https://crates.io/crates/tauri-delta-updater/0.4.0) ·
[docs.rs](https://docs.rs/tauri-delta-updater/0.4.0) ·
[npm](https://www.npmjs.com/package/tauri-plugin-delta-updater/v/0.4.0)

## 升级注意

- **默认权限收窄**：`delta-updater:default` 现在只包含增量更新、检查、诊断、
  取消与跨重启安装。前端调用 `installFull()` / `downloadFull()`，或使用
  `checkCompat()` 的自动全量回退时，需要给对应窗口补上
  `delta-updater:full`。已有 capability 文件不会被自动改写，
  `cargo delta init --check` 会指出缺失项。
- **Rust 匹配代码**：安全模式结果现在携带原因（`SafeMode` 的 `reason`）；
  环境回退原因改为结构化值；全量安装失败携带失败类型。只匹配变体名、
  或按旧元组字段取值的代码需要补字段或改用 `..`。
- **发布工具**：`--base-url` 默认要求带主机名的 HTTPS。内网联调或本地桶
  需要显式加 `--allow-http`；`--from` 现在同时接受目录和单个主程序。
- **新增配置均为可选**：`authenticode_policy` 默认 `strict`，
  `lock_scope` 默认 `work_dir`，不配置时行为与 0.3 一致。

## 新增

- **能区分原因的失败结果**：安全模式会说明是签名/哈希阻断、环境问题
  （磁盘/权限）还是网络重试耗尽；环境回退会说明是 AppImage 目录只读、
  无法定位 AppImage 本体、macOS bundle 还是系统版本不足。
- **跨版本更新更透明**：多跳补丁链总下载量超过全量安装包预算时，结果会
  明确报告 `chain_over_budget`，而不是显示“没有补丁”。
- **安装失败可精确处理**：用户取消 UAC/授权、安装器非零退出、平台不匹配、
  安装器不存在等都有独立类型，前端可以显示“已取消”而不是笼统报错。
- **企业离线环境的签名策略**：`authenticode_policy: "permissive"` 允许
  “证书链不在缓存、无法验证”只告警；明确未签名/被拒绝仍然阻断。
- **多用户机器的更新锁**：`lock_scope: "install_dir"` 在安装目录增加一把
  跨用户锁；目录只读时自动退回工作目录锁并记录警告。
- **接入辅助**：`cargo delta init` 会根据是否配置引擎安装器自动补
  `delta-updater:full`；新增按场景划分的接入索引、配置速查/决策树、
  官方 updater 迁移前后端示例与 macOS 一键验证脚本。

## 修复

- Linux `.deb` / `.rpm` 全量包在下载前直接拒绝，并提示改用发行版包管理器
  或 AppImage，不再下载一个无法自动安装的包。
- 并发补丁任务在进程内串行化，避免内存峰值叠加与临时产物互相覆盖。
- 回滚原因与启动状态改为原子写入；已有更具体原因时不再被
  `update_failed` 覆盖，并记录“原因被保留”事件。
- `check()` 不再清理已准备好的待安装更新；更新失败也不会丢掉旧 pending。
- 清单、签名、备用与整包地址在构造阶段校验，非 HTTP(S) 端点不再等到
  第一次请求才失败。
- `cargo delta doctor` 增加备用端点体检与英文关键词输出，镜像落后/404
  会在发布后立即暴露。

## 验证边界

- macOS Gatekeeper/公证、Windows UAC/单实例、Linux 提权路径未在本仓库
  真机验证；CI 只做静态与合成脚本断言。
- `authenticode_policy: "permissive"` 已做决策单元测试，未在真实离线证书链
  环境中验证。
- `lock_scope: "install_dir"` 未用两个真实用户账户并发验证。
- `cargo delta doctor` 只在本地 mock server 端到端验证过，未对真实 CDN 执行。

本版本发布后不可覆盖；后续版本须经项目所有者明确授权。
